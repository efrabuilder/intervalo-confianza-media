intervalo-confianza-media

Intervalo de confianza para la media, con el estadístico Z.

IC = x̄ ± z · (s / √n). Empezá con lo que tengas a mano: un resumen con x̄, s y n, o la lista completa de datos.

Se calculan x̄, s y n automáticamente. Se necesitan al menos 2 datos.

Procedimiento

    Fórmula

    IC = x̄ ± z · (s / √n)

    Rango de valores donde se estima que está la media poblacional real (μ), con un nivel de confianza dado. Usa el estadístico Z cuando se conoce (o se aproxima) la desviación estándar — por ejemplo, cuando n ≥ 30, o cuando el ejercicio lo indica directamente.

    La misma lógica vive en ic.py para usar desde la línea de comandos (main.py).
