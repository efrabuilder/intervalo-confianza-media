Intervalo de confianza para la media, con el estadístico Z.

IC = x̄ ± z · (s / √n). Empezá con lo que tengas a mano: un resumen con x̄, s y n, o la lista completa de datos.

Se calculan x̄, s y n automáticamente. Se necesitan al menos 2 datos.

Procedimiento

    Definiciones y fórmulas

    Media muestral (x̄)

    x̄ = Σxᵢ / n

    El promedio de los datos de la muestra. Es el punto central alrededor del cual se construye el intervalo de confianza.

    Desviación estándar (s)

    s = √[Σ(xᵢ − x̄)² / (n − 1)]

    Mide qué tan dispersos están los datos respecto a la media. Cuanto mayor es, más ancho será el intervalo de confianza.

    Tamaño de muestra (n)

    n = cantidad de datos

    La cantidad de observaciones usadas para estimar la media. Muestras más grandes producen intervalos más angostos (más precisos).

    Valor crítico (z)

    z según nivel de confianza

    Un valor fijo de la distribución normal estándar que depende del nivel de confianza elegido: 1.645 (90%), 1.96 (95%) o 2.576 (99%). Indica cuántos errores estándar hay que alejarse de x̄ para cubrir ese porcentaje de casos.

    Error estándar (EE)

    EE = s / √n

    Estima qué tan lejos podría estar la media de la muestra respecto a la media real de la población. Disminuye a medida que aumenta n.

    Margen de error (E)

    E = z · (s / √n)

    La distancia que se suma y resta a x̄ para formar el intervalo. Combina qué tan confiables queremos ser (z) con qué tan precisa es la estimación (EE).

    Intervalo de confianza

    IC = x̄ ± z · (s / √n)

    El rango de valores donde se estima que está la media poblacional real (μ), con el nivel de confianza elegido. Usa el estadístico Z cuando se conoce (o se aproxima) la desviación estándar — por ejemplo, cuando n ≥ 30, o cuando el ejercicio lo indica directamente.

    La misma lógica vive en ic.py para usar desde la línea de comandos (main.py).
